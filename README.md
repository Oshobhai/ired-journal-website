# IRED Journal Platform

Phase 1 of the Institute of Research Education and Development (IRED) journal platform.

## Publication model
- **GREEN: The Research Journal** — individual research papers
- **RED: The Research Journal** — research books / compiled volumes

## Included in Phase 1
- Responsive public homepage
- GREEN papers listing
- RED books listing
- About IRED
- Editorial Board / Review Committee
- Author Guidelines
- Contact page
- Admin dashboard skeleton
- Supabase schema blueprint

## Planned Phase 2
- Supabase Auth for admins
- Student submission workflow
- Persistent database
- PDF/DOCX storage
- Review / accept / publish workflow
- RED book management

The project is designed for deployment on Vercel with Supabase for database, authentication, and storage.
